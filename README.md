# THE WHISTLES 🎸

Jogo musical de navegador — **THE WHISTLES V13**.

## Jogar

https://ryusarto.github.io/The-whistles/

## Conteúdo

- Músicas: **Nexus, Summertime, Ruthless, Sem Tu e Minha Fonte**.
- Dificuldades Easy, Normal, Expert; notas e recordes.
- Modos **Solo** e **Duo Local**: guitarra (Franco) e baixo (Ryuchi).
- Controle PS5 DualSense: L2, L1, R1, R2 (pistas 1–4); ✕ especial; OPTIONS pausa.
- Suporte a 2 controles pelo Gamepad API em navegadores compatíveis.

## Publicação

O arquivo `index.html` é a entrada do GitHub Pages. Todo o áudio e imagens fica em `assets/`. Os arquivos são servidos por caminhos relativos, de modo que funcionam no subdiretório do repositório.

No GitHub: Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
