# THE WHISTLES 🎸

Jogo musical de navegador — versão V13.

O GitHub Pages deve servir o jogo em: https://ryusarto.github.io/The-whistles/

Modos Solo e Duo Local, com guitarra e baixo, cinco músicas e controles DualSense L2 / L1 / R1 / R2.

Para ativar a hospedagem, acesse Settings → Pages → Deploy from a branch → main → /(root).
